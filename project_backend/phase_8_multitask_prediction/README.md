# Phase 8 — Multi-Task Disease Prediction Network (Stroke + Alzheimer's Disease)

## 1. Overview & Purpose
Phase 8 implements the **Multi-Task Disease Prediction Network**, the clinical diagnostic inference stage of the multimodal pipeline. It takes the **Unified Patient Representation (UPR)** generated by **Phase 7** ($[B, 512]$) and produces decoupled, simultaneous predictions for:

1. **Stroke**
2. **Alzheimer's Disease**

> [!WARNING]
> **RESEARCH PROTOTYPE NOTICE**:
> This software is an academic/research model. Model outputs represent statistical predictions and **MUST NOT** be used as clinical diagnostic claims.

## 2. Core Architectural Components

### A. Shared Prediction Trunk (`shared_network.py`)
- Maps the $[B, 512]$ UPR vector into a shared $256$-dimensional multimodal latent space.
- Extracts features informative for both neurodegenerative (Alzheimer's) and cerebrovascular (Stroke) pathways.

### B. Independent Disease Prediction Heads (`prediction_heads.py`)
- **Stroke Head**: Decoupled binary classifier outputting raw logit $[B, 1]$.
- **Alzheimer's Head**: Decoupled binary classifier outputting raw logit $[B, 1]$.
- Supports inference probability extraction ($\sigma(\text{logit})$) and decision thresholding ($\ge 0.5$).

### C. Masked Multi-Task Loss (`loss.py`)
- Handles missing patient labels without requiring fabricated data:
  $$L_{\text{total}} = \lambda_{\text{stroke}} L_{\text{stroke}} + \lambda_{\text{alzheimer}} L_{\text{alzheimer}}$$
- Averages losses strictly over labelled patient samples; handles empty task batches safely with zero loss (avoiding NaNs).

### D. Multi-Task Metrics Calculator (`metrics.py`)
- Computes Accuracy, Precision, Recall, Specificity, F1-score, ROC-AUC, PR-AUC, and Confusion Matrices for each task independently.

### E. Phase 9 & Phase 10 Compatibility
- **Phase 9**: Prepares an explicit `enable_mc_dropout=True` parameter to allow stochastic forward passes for Monte Carlo Dropout uncertainty estimation.
- **Phase 10**: Exposes `shared_features` tensor for downstream Grad-CAM / SHAP explainability.

## 3. How to Run Phase 8

Execute from `project_backend/`:

### 1. View Multi-Task Architecture Summary:
```powershell
python -m phase_8_multitask_prediction.main summary
```

### 2. Predict Disease Outcomes from Saved UPR Tensor:
```powershell
python -m phase_8_multitask_prediction.main predict \
    --upr phase_7_retina_clinical_fusion/outputs/unified_patient_representation.pt \
    --output phase_8_multitask_prediction/outputs/multitask_predictions.pt
```
